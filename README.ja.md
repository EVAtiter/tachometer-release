# Tachometer Plus / Tachometer Lite

Mac の CPU・GPU・ネットワーク・ディスク・メモリー・消費電力・温度を、自動車のメーター風の計器で表示する macOS メニューバー常駐アプリ。

**➡️ [最新版をダウンロード](https://github.com/EVAtiter/tachometer-release/releases/latest)**

このリポジトリで配布しているのは、すべての計器を備えた Developer ID 署名版 **Tachometer Plus** です。消費電力・GPU・ANE・温度を除いた版を、Mac App Store で **Tachometer Lite** として配布しています（インストール後のアプリ名は Tachometer）。

## 計器構成

| 計器 | Tachometer Lite | Tachometer Plus |
| --- | --- | --- |
| CPU/GPU メーター（タコメーター） | CPU の針のみ | ✅ CPU・GPU の針 + ANE 警告灯 |
| ネットワーク下り / 上り | ✅ | ✅ |
| ディスク読み込み / 書き込み | ✅ | ✅ |
| 空きメモリー（燃料計） | ✅ | ✅ |
| 消費電力計（Mac 全体の消費電力） | — | ✅ |
| CPU 温度計 / GPU 温度計 | — | ✅ |
| システムモニター | CPU の推移のみ | ✅ CPU・消費電力の推移 + GPU・ANE ゲージ |

各計器は独立したウインドウで表示され（どこへでもドラッグ配置でき、ディスプレイごとに位置を記憶）、メニューから個別に表示 / 非表示を切り替えられます。CPU/GPU メーターと温度計は、初期状態では非表示です。

## 機能

- **ピーク学習による相対スケール**（トラフィック系計器）— 「100%」はあなたの Mac が実際に観測したピーク値。メニューの「ピーク記憶設定...」でスライディングウィンドウ（5 分〜1 時間）または ∞（再起動をまたいで記憶）を選べます。ピークを学習している間はブルーの警告灯が点滅します。
- **メモリープレッシャー警告** — 空きメモリー計の警告灯は、macOS 自身のメモリープレッシャー信号（正常 / 警告 / 危険）に連動して琥珀色に点灯・点滅します。
- **消費電力のピーク記憶**（Plus 限定）— 消費電力計は期間を区切らず観測した最大値を記憶し続けます。新しいピークを更新中は警告灯がグリーンに点滅します。
- **ANE 警告灯**（Plus 限定）— CPU/GPU メーターの警告灯は、Apple Neural Engine が動くとピンクに点灯し、使用率が上がると点滅します。
- **温度計**（Plus 限定）— CPU と GPU の温度を 40〜100℃ の目盛りで表示します。85℃ で警告灯が点灯、95℃ で点滅します。
- **システムモニター** — CPU と消費電力の推移を約 50 秒ぶん、キューブの積み上げで描きます。並べ方は「重ねる」「上下に分ける」「中央から伸ばす」の 3 通り（Plus のみ）。クリックすると数値表示に切り替わります。
- **メーターを集める** — CPU/GPU メーターの位置を起点に、残りの計器を整列させます。
- **画面下端で呼び出す** — 画面のいちばん下にカーソルを 0.5 秒ほど置くと、計器が手前に出てきます（初期状態はオフ）。
- **静かな針** — 針の動きは平滑化されており、アイドル時はぴたりと静止。起動やスリープ復帰時にはイグニッション風のニードルスイープ演出があります。
- **2 種類のシンボルセット** — 「クラウド / トレイ」と「ミニマル矢印」をメニューから切替できます。
- **ウインドウの置き方** — 「常に最前面」と「壁紙に貼り付ける」（壁紙にピン留め・クリック貫通）。どちらもオフなら通常のウインドウです。
- **Day / Night 照明** — システム外観に追従、または Day（白）/ Night（琥珀の計器照明）に固定。
- **日本語 / 英語対応** — システム言語に追従します。

## 動作環境

- macOS 14 Sonoma 以降
- Apple Silicon（arm64）専用

## インストール

### Homebrew

```
brew install --cask EVAtiter/tap/tachometer
```

### 手動

1. [Releases](https://github.com/EVAtiter/tachometer-release/releases/latest) から `Tachometer-Plus-<version>.zip` をダウンロード
2. 解凍して `Tachometer Plus.app` を `/Applications` へ移動
3. 起動するとメニューバー（ゲージアイコン）に常駐します（Dock には表示されません）

バイナリは Developer ID 署名 + Apple 公証済みです。Tachometer Plus は App Sandbox なしで動作します（消費電力・GPU・ANE の稼働状況・温度を読み取るために必要なため）。

## 使い方

- 操作はすべてメニューバーのゲージアイコンから: 計器ごとの表示切替・メーターを集める・画面下端で呼び出す・ピーク記憶設定・ウインドウの置き方・照明・シンボル・システムモニターの並べ方。
- 計器ウインドウの右クリックでも同じメニューが開きます。
- 計器はドラッグで移動でき、位置はディスプレイごとに記憶されます。
- システムモニターをクリックすると、グラフと数値表示が切り替わります。

## 背景

計測部は [Gigant Monitor](https://github.com/EVAtiter/gigant-monitor-support) と共通、アナログメーター描画は Fuel Level Plus のスポーツスタイル文字盤から育ったもの。空きメモリー計と消費電力計は、実は Fuel Level Plus の燃料計と消費電力計そのものを Tachometer の文字盤スタイルで描き直したものです。実際のシステムの活動を、本物らしい計器で眺めるアプリです。
